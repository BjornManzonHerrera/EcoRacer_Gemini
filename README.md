# EcoRacer

A futuristic racing game with an ecological theme. Players can customize their characters and vehicles, compete in races, and climb the leaderboards.

![EcoRacer Gameplay](https://placehold.co/600x400/152823/ffffff?text=EcoRacer)

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

*   [Node.js](https://nodejs.org/) (v18.x or later)
*   [npm](https://www.npmjs.com/)

### Installation

1.  Clone the repository:
    ```sh
    git clone https://github.com/BjornManzonHerrera/EcoRacer_Gemini.git
    ```
2.  Navigate to the project directory:
    ```sh
    cd EcoRacer_Gemini/ecoracer-app
    ```
3.  Install NPM packages:
    ```sh
    npm install
    ```

### Running the Application

*   To run the app in development mode:
    ```sh
    npm run dev
    ```
    Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

*   To build the app for production:
    ```sh
    npm run build
    ```

## ✨ Features

*   **Character Customization:** Personalize your racer's appearance.
*   **Vehicle Selection:** Choose from a variety of futuristic, eco-friendly vehicles.
*   **Competitive Racing:** Compete on dynamic race tracks.
*   **Leaderboards:** Track your progress and compete for the top spot.
*   **Challenges:** Complete daily and weekly challenges to earn rewards.
